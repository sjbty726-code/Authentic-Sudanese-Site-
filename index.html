حوّل مشروعك إلى APK

جهّز مشروع أندرويد حقيقي يحتوي على صفحة المعاينة الحالية داخل WebView وملف بناء تلقائي. بعدها ارفع ملفات ZIP إلى مستودع GitHub، وسيبني GitHub ملف APK وينشره كـ Artifact.

01

جهّز مشروع APK

سيتم تضمين النتيجة الحالية التي تراها في المعاينة، مع ملفات الموقع الأصلية وملفات Gradle وWorkflow للبناء.

الزر يجهّز ملفات المشروع فقط؛ البناء الفعلي يجري على GitHub بعد رفع الملفات وتشغيل Actions.

02

اربط مستودع GitHub لمتابعة البناء

الصق رابط المستودع العام الذي رفعت إليه مشروع ZIP وفككت ملفاته. مثال: https://github.com/اسمك/اسم-المستودع

جاهز للفحص

أدخل رابط مستودع عام ثم اضغط «فحص حالة البناء».

03

كيف تنزّل APK؟

  1. نزّل ZIP من الخطوة الأولى وفك ضغطه.
  2. ارفع محتويات المجلد إلى مستودع GitHub جديد، مع الحفاظ على مجلد .github/workflows.
  3. افتح تبويب Actions. يبدأ البناء تلقائياً بعد رفع الملفات، أو شغّل Build Android APK يدوياً.
  4. عند نجاح البناء، افتح أحدث تشغيل ثم قسم Artifacts ونزّل wad-faisal-debug-apk.

لو فشل البناء، ستعرض هذه الواجهة اسم المهمة والخطوة الفاشلة للمستودعات العامة. افتح سجل التشغيل في GitHub لعرض رسالة الخطأ الكاملة. المستودعات الخاصة تحتاج صلاحية دخول لا توفرها صفحة HTML العامة.
